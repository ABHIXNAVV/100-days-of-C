▶️ How to Run
1. Clone the repository
git clone https://github.com/ABHIXNAVV/100-days-of-C.git
2. Open the repository
cd 100-days-of-C
3. Navigate to any day's folder

For example:

cd Day-01
4. Compile a C program
gcc program1.c -o program1.exe
5. Run the program

On Windows PowerShell:

.\program1.exe
🔄 Daily Workflow

For every problem, I follow this process:

Read and understand the problem.
Identify the required logic.
Write the C program.
Compile the program.
Test it using sample inputs.
Fix errors if necessary.
Save the verified solution.
Commit the changes using Git.
Push the changes to GitHub.

Example:

git add .
git commit -m "Day 35 completed"
git push
